## 麻将框架使用说明

### 文件结构

```
框架.py                 # 主游戏框架
score_calculator.py    # 番种计算模块（预留接口）
全番斗规则集.txt       # 规则文档
demo.py               # 格式演示脚本
```

### 牌的简称系统

框架使用简洁的英文简称表示麻将牌：

**数牌：**
- `1m-9m`: 一万到九万
- `1p-9p`: 一筒到九筒  
- `1s-9s`: 一条到九条

**字牌：**
- `E`: 东（East）
- `S`: 南（South）
- `W`: 西（West）
- `N`: 北（North）
- `C`: 中（Center）
- `F`: 发（Fortune）
- `P`: 白（Pin/White）

### 当前框架特性

✅ **已实现：**
- 完整的游戏流程（局前→发牌→回合循环→流局或和牌→结算）
- 单人玩家 + 3个AI
- **交互式选择**：
  - 鸣牌阶段：玩家可选择自摸、暗杠、加杠
  - 出牌阶段：玩家用简称选择打哪张牌（**横向显示，无序号**）
  - 待鸣阶段：玩家可选择碰、杠、吃、荣
- AI策略：不鸣牌，每次打摸到的牌
- 牌的表示与管理（34种牌，每种4张）
- 和牌判定（标准和牌、七对、十三幺）
- 基础的分数计算框架
- 多盘游戏管理与最终排名

⏳ **待补充：**
- 具体的番种计算规则（在 `score_calculator.py` 中）
- 番种判定的详细逻辑

### 核心类说明

#### `Tile` - 麻将牌
```python
tile = Tile(TileType.MAN, 5)    # 5万
tile = Tile(TileType.HONOUR, 4) # 中（rank 4 = 中发白中的中）
```

#### `Player` - 玩家
```python
player.hand          # 手牌列表
player.melds         # 副露列表（碰、杠等）
player.status_flag   # 状态标：None/MELD/KONG
player.discards      # 打出的牌
```

#### `MeldSet` - 副露
```python
meld = MeldSet(
    tiles=[tile1, tile2, tile3],
    meld_type='PUNG',      # CHOW(吃)/PUNG(碰)/KONG(杠)/DARK_KONG(暗杠)
    hidden_count=2         # 暗置牌数（暗杠用）
)
```

#### `Game` - 游戏主类
```python
game = Game()
game.initialize_game()    # 初始化
game.play_game(4)         # 进行4盘
```

### 核心流程（按规则实现）

1. **局前阶段**：决定起东
2. **盘前阶段**：
   - 洗牌、码放成136张牌（34墩）
   - 东家投掷骰子确定起牌家
   - 发牌：每家13张
3. **盘中阶段**（循环直到和牌或流局）：
   - 摸牌阶段：根据状态标从牌山头/尾摸牌
   - 鸣牌阶段：检查自摸、暗杠、加杠
   - 出牌阶段：打出一张牌
   - 待鸣阶段：其他玩家响应（碰/杠/吃/荣）
4. **盘后阶段**：计算分数
5. **局后阶段**：最终排名

### 已知限制

- AI不响应鸣牌（碰、杠、吃、荣）
- AI总是打最后摸到的牌
- 人类玩家也会自动打最后一张牌（可扩展为交互式选择）
- 暂未实现番种计算的完整规则

### 简称小贴士

- 简称输入时**不区分大小写**（`1m` 和 `1M` 均可）
- 如果输入的简称不在手牌中，会收到 `不在你的手牌中` 的提示，可直接重新输入
- 手牌始终以从左到右（从小到大）的顺序显示
- 副露（已碰杠的牌）不显示在手牌列表中

### 运行示例

```bash
python 框架.py
```

**交互流程示例：**

1. **鸣牌阶段** - 如果满足条件会显示可选操作：
   ```
   [东(人类) 的回合 - 鸣牌阶段]
   当前手牌(14张)：2m 6m 9m 9m 2p 6p 8p 5s 7s 8s 9s 9s P
   可选操作：
     1. 自摸（标准和）
     0. 不鸣牌，继续出牌
   请选择（输入序号）：
   ```

2. **出牌阶段** - 输入简称选择要打出的牌：
   ```
   [东(人类) 的回合 - 出牌阶段]
   手牌(14张)：2m 6m 9m 9m 2p 6p 8p 5s 7s 8s 9s 9s P
   请输入要打出的牌的简称：2m
   东(人类) 打出：2万 (2m)
   ```
   
   **说明：**
   - 手牌横向显示，直接输入简称即可
   - 如果输入的简称不在手牌中，会提示重新输入
   - 简称不区分大小写

3. **待鸣阶段** - 其他玩家可以鸣牌：
   ```
   [待鸣阶段] 牌河中的牌：2m
   
   [南(AI) 的回合 - ...] (AI不响应)
   
   [西(人类) 的可选操作：
     1. 碰
     2. 杠
     4. 荣
     0. 不鸣牌
   请选择（输入序号）：0
   ```
